# Enhanced Chase Camera

### Авторы плагина: Reki, LegacyDEVV

Аркадная камера с эффектами скорости и гибкой настройкой:

- динамический FOV

- крен на поворотах

- реакция на прыжки

- тряска на высокой скорости.

## Использование

Камера активируется через штатное переключение режимов камеры: кнопка С или круговое меню. Работает только в автомобиле.

`Shift+C` — открыть/закрыть окно настроек камеры

## Настройка

Для настроек доступны такие параметры как:
— базовый FOV, дистанция и высота камеры
— наклон при разгоне/прыжках, крен на поворотах, отставание камеры в заносе, тряска на скорости
— скорость нарастания/спада эффекта отъезда камеры при разгоне/торможении

Во вкладке **"Пресеты"** доступно сохранение собственных настроек
Во вкладке **"Информация"** доступна краткая сводка по использованию

Язык интерфейса применяется согласно языку, установленному в настройках игры

## Совместимость

Требуется: MadOut2 PC 9.4 с BigCityLegacy 1.4.0+
