# Enhanced Chase Camera

### 插件作者：Reki、LegacyDEVV

带有速度效果和灵活设置的街机风格追尾摄像机：

- 动态 FOV

- 转弯横滚

- 跳跃响应

- 高速抖动

## 使用方法

通过游戏原有的摄像机切换方式启用：按 C 键或使用环形菜单。仅在驾驶车辆时生效。

`Shift+C` — 打开 / 关闭摄像机设置。

## 设置

可调整的参数包括：

- 基础 FOV、摄像机距离和高度

- 加速及跳跃时的俯仰、转弯横滚、漂移时的跟随滞后和高速抖动

- 加速及制动时摄像机拉远和回位的速度

**Presets（预设）** 选项卡可保存自定义设置。

**Info（信息）** 选项卡提供简要使用说明。

界面语言跟随游戏设置中的语言。

## 兼容性

需要 MadOut2 PC 9.4 和 BigCityLegacy 1.4.0+。
