# Enhanced Chase Camera

### Plugin authors: Reki, LegacyDEVV

An arcade-style chase camera with speed effects and flexible settings:

- Dynamic FOV

- Cornering roll

- Jump response

- High-speed shake

## Usage

Activate the camera using the game's standard camera switch: the C key or the radial menu. It works only while driving a vehicle.

`Shift+C` — open / close camera settings.

## Settings

Available settings include:

- Base FOV, camera distance and height

- Pitch during acceleration and jumps, cornering roll, drift lag and speed shake

- How quickly the camera pulls back and returns during acceleration and braking

The **Presets** tab lets you save your own settings.

The **Info** tab provides a brief usage guide.

The interface follows the language selected in the game's settings.

## Compatibility

Requires MadOut2 PC 9.4 with BigCityLegacy 1.4.0+.
