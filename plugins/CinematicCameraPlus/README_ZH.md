# Cinematic Camera Plus

### 插件作者：[Mr_Dodep](https://t.me/MrDodep_1337)

用于调整电影风格摄像机和视觉效果的模组。所有更改仅在本地生效，只有你自己能看到。

---

## 安装

1. 将 `CinematicCameraPlus.dll` 复制到 `BepInEx/plugins/`。
2. 启动游戏。
3. 按 **Alt + C** 打开模组菜单。

---

## 菜单选项卡

### Camera（摄像机）

- **FOV** — 摄像机视野角度（20°–120°），提供 60°、75°、90°、45° Cinematic 和 35° Portrait 快捷按钮

- **Camera Roll（横滚）** — 向左或向右倾斜（-45° 至 +45°），提供 -15° / 0° / +15° 按钮

- **Letterbox（宽银幕黑边）** — 2.39:1 / 2.35:1 / 1.85:1 比例的电影黑边

### Color（色彩）

- **亮度** — -1.0 至 +1.0

- **对比度** — 0.5 至 2.0

- **饱和度** — 0.0 至 2.0（0 为黑白）

- **伽马** — 0.5 至 2.0

### Effects（效果）

- **暗角** — 压暗画面边缘

- **色差** — 画面边缘的颜色偏移

- **扫描线** — 模拟老式显示器的水平条纹

- **胶片颗粒** — 每帧生成随机噪点

- **夜视** — 绿色色调与压暗效果

- **棕褐色** — 棕黄色调

- **红外** — 用红色色调模拟红外摄像机

- **雾 / 薄雾** — 乳白色覆盖效果

- **老式电视** — 干扰条纹、滚动扫描线与泛黄效果

- **日落** — 橙色 → 金色 → 紫色的暖色渐变

### Presets（预设）

内置预设会同时调整 FOV、色彩和效果：

| 预设 | 描述 |
|---|---|
| Cinematic | FOV 50、提高对比度、暗角、宽银幕黑边 |
| Noir | 黑白、高对比度、颗粒 |
| Sunset | 暖色调、提高饱和度 |
| Cold Night | 蓝色色调、压暗、色差 |
| Vintage | 颗粒、扫描线、旧胶片风格 |
| Horror | 暗绿色调、暗角 |
| Vivid | 明亮色彩、提高饱和度 |
| Default | 重置所有设置 |

## 说明

- 即使其他插件尝试覆盖 FOV，视野调整仍然有效。

- 可通过“关闭所有效果”按钮一次性关闭所有效果。

- 再次按 **Alt + C** 或点击鼠标右键可关闭菜单。
