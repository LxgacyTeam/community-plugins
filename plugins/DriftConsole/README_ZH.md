# DriftConsole

### 插件作者：一只 car

漂移模式，可灵活设置（动力、转向、方向盘抓地力）和评分。

## 操作

`Alt+D` — 打开 / 关闭设置窗口。

## 功能

- 可调整动力倍率、最大转向角、转向灵敏度和回正灵敏度

- 可调节强度的转向辅助

- 前后轮的横向与纵向抓地力可分别设置

- 漂移模式和漂移计分的独立开关

- 两种计分样式：**Classic**（带圆环的经典计分器）和 **Flat**（简洁面板）

- 菜单支持俄文、英文和中文

已应用的数值会自动保存到 `BigCityLegacy/config/Drift config.txt`。

## 兼容性

需要 MadOut2 PC 9.4 和 BigCityLegacy 1.4.0+。
