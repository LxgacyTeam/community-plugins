# DriftConsole

### Plugin author: 一只 car

Drift mode with flexible settings (power, steering, tire grip) and a scoring system.

## Controls

`Alt+D` — open / close settings.

## Features

- Adjustable power multiplier, maximum steering angle, steering sensitivity and return sensitivity

- Steering assist with adjustable strength

- Separate lateral and longitudinal grip settings for the front and rear wheels

- Toggles for drift mode and drift scoring

- Two counter styles: **Classic** (the original counter with a ring) and **Flat** (a compact panel)

- Russian, English and Chinese menu languages

Applied values are saved automatically to `BigCityLegacy/config/Drift config.txt`.

## Compatibility

Requires MadOut2 PC 9.4 with BigCityLegacy 1.4.0+.
