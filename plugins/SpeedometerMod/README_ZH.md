# Speedometer Mod

### 插件作者：[UserRP](https://t.me/NameDayn)、一只 car

Speedometer Mod 为游戏添加美观且可自定义的速度表。提供四种样式，从经典的半圆指针表盘到现代赛车游戏风格的数字显示。

## 设置与使用

可将速度表放在屏幕左侧、中央或右侧，并选择喜欢的样式。设置菜单支持俄文、英文和中文。

默认按 `Alt+S` 打开菜单，只需几步即可重新绑定快捷键。

## 兼容性

需要 MadOut2 PC 9.4 和 BigCityLegacy 1.4.0+。
