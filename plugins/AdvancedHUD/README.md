# AdvancedHUD

### Plugin author: [Mr_Dodep](https://t.me/MrDodep_1337)

Customizable HUD widgets.

## Controls

| Shortcut | Action |
|---|---|
| Alt+X | Open / close settings |

## Features

### Compass

A horizontal compass bar at the top of the screen shows the camera's direction in real time.

- Cardinal directions: N / E / S / W

- Degree labels with adjustable spacing

- Minor ticks every 10°

- Central arrow marking the current heading

- Numeric heading below the bar

- Customizable position, size, font sizes, field of view, colors and border

### HUD widgets

Seven independent floating windows: each can be **dragged**, has a **translucent background**, and can be enabled or disabled separately.

| Widget | Contents |
|---|---|
| **Vehicle** | Large speed display (km/h), gear (R/N/1–6), RPM and progress bar, nitro multiplier, engine status |
| **Health** | Player HP and progress bar; vehicle HP and progress bar |
| **Weapons** | Scrollable weapon list with ammunition counts; the active weapon is highlighted in yellow with `▶` |
| **Position** | Player and camera X/Y/Z coordinates; click a button to copy coordinates to the clipboard |
| **Performance** | FPS, frame time (ms), low-FPS percentage, Mono memory usage (MB), FPS progress bar |
| **Session** | Time elapsed since the game started (`HH:MM:SS`) |
| **Clock** | Current local time on your PC (`HH:MM:SS`) |

### Settings window (Alt+X)

A scrollable settings panel provides:

- Individual widget visibility toggles

- A compass visibility toggle

- Global widget background opacity and Backdrop Blur controls

- A collapsible **Compass Settings** section with visibility toggles for degrees, cardinal directions, the center marker, numeric heading, ticks and border

- Sliders for Y position, X offset, width, height, degree spacing and field of view

- Sliders for cardinal, degree and heading font sizes, and border thickness

- RGB sliders for each compass element

- **Reset Positions** to return all widgets to their default locations
