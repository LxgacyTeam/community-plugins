# AdvancedHUD

### 插件作者：[Mr_Dodep](https://t.me/MrDodep_1337)

可自定义的 HUD 信息组件。

## 操作

| 快捷键 | 功能 |
|---|---|
| Alt+X | 打开 / 关闭设置窗口 |

## 功能

### 指南针

屏幕顶部的水平指南针实时显示摄像机朝向。

- 方位标记：N / E / S / W

- 可调整间隔的角度标记

- 每 10° 一个细刻度

- 指示当前朝向的中央箭头

- 指南针下方显示当前朝向角度

- 可自定义位置、大小、字号、视野角度、颜色和边框

### HUD 组件

七个独立浮动窗口，均可**拖动**，具有**半透明背景**，并可单独开启或关闭。

| 组件 | 显示内容 |
|---|---|
| **Vehicle** | 大号车速显示（km/h）、挡位（R/N/1–6）、转速及进度条、氮气倍率、发动机状态 |
| **Health** | 玩家生命值及进度条、车辆生命值及进度条 |
| **Weapons** | 可滚动的武器与弹药列表；当前武器以黄色和 `▶` 标记 |
| **Position** | 玩家与摄像机的 X/Y/Z 坐标；点击按钮可将坐标复制到剪贴板 |
| **Performance** | FPS、帧时间（ms）、低帧率占比、Mono 内存占用（MB）、FPS 进度条 |
| **Session** | 游戏启动后的运行时长（`HH:MM:SS`） |
| **Clock** | 电脑当前的本地时间（`HH:MM:SS`） |

### 设置窗口（Alt+X）

可滚动的设置面板提供：

- 各组件的显示开关

- 指南针显示开关

- 所有组件背景的统一透明度和 Backdrop Blur（背景模糊）设置

- 可折叠的 **Compass Settings（指南针设置）**，可切换角度、方位、中央标记、当前角度、刻度和边框的显示

- Y 位置、X 偏移、宽度、高度、角度间隔和视野角度滑块

- 方位、角度及当前朝向的字号滑块，以及边框粗细滑块

- 各指南针元素的 RGB 颜色滑块

- **Reset Positions（重置位置）** 按钮，将所有组件恢复到默认位置
