# AdvancedHUD

### Автор плагина: [Mr_Dodep](https://t.me/MrDodep_1337)

Настраиваемые HUD виджеты

## Управление

| Сочетание клавиш | Действие |
|---|---|
| Alt+X | Открыть / закрыть окно настроек |


## Возможности

### Компас

Горизонтальная полоска компаса в верхней части экрана, показывающая направление камеры в реальном времени.

- Стороны света: N / E / S / W 

- Метки градусов с настраиваемым шагом 

- Мелкие засечки на каждые 10°

- Центральный маркер-стрелка текущего курса

- Числовой показ текущего градуса под полоской

- Полная кастомизация: позиция, размер, размеры шрифтов, угол обзора, цвета, рамка

### HUD-виджеты

Семь независимых плавающих окон — каждое **перетаскивается**, **полупрозрачно** и включается/выключается отдельно.

| Виджет | Содержимое |
|---|---|
| **Vehicle** | Крупная скорость (км/ч), Передача (R/N/1–6), Обороты + шкала, Множитель нитро, Состояние двигателя |
| **Health** | HP игрока + шкала, HP машины + шкала |
| **Weapons** | Прокручиваемый список всего оружия с боезапасом; активное оружие выделено жёлтым с `▶` |
| **Position** | Координаты X/Y/Z игрока и камеры; клик по кнопке копирует координаты в буфер обмена ПК |
| **Performance** | FPS, время кадра (мс), процент низкого FPS, потребление памяти Mono (МБ), шкала FPS |
| **Session** | Время, прошедшее с запуска игры (`ЧЧ:ММ:СС`) |
| **Clock** | Текущее локальное время на ПК (`ЧЧ:ММ:СС`) |

### Окно настроек (Alt+X)

Прокручиваемая панель настроек:

- Переключатели виджетов (показать/скрыть каждое окно)

- Переключатель компаса

- Общая прозрачность фона виджетов и переключатель Backdrop Blur

- **Настройки компаса** (сворачиваемая секция):
  - Вкл/выкл: градусы, стороны света (N/E/S/W), центральный маркер, текущий градус, засечки, рамка
  - Слайдеры: позиция Y, смещение X, ширина, высота, шаг градусов, угол обзора
  - Слайдеры: размеры шрифтов для сторон света, градусов и текущего курса; толщина рамки
  - Слайдеры цвета (R/G/B) для каждого элемента компаса

- Кнопка **«Сбросить позиции»** — возвращает все виджеты на стандартные места
