# BCL plugin templates

Три независимых шаблона для MadOut2 PC 9.4 / BepInEx 5 / net472:

| Каталог | BCL API | LegacyUIFramework | Пример |
| --- | --- | --- | --- |
| [Basic](Basic/README_RU.md) | Нет | Нет | BaseUnityPlugin, конфигурация |
| [UI](UI/README_RU.md) | Нет | Да | Окно, масштабирование, toggle, курсор |
| [ApiUI](ApiUI/README_RU.md) | Да | Да | Активация, диалог, alert, перезапуск |

Сборка и настройка путей описаны в README каждого проекта. Перед публикацией собственного плагина замените примерные GUID/название/автора и выберите лицензию своего кода.
