# BCL plugin templates

Three independent templates for MadOut2 PC 9.4 / BepInEx 5 / net472:

| Directory | BCL API | LegacyUIFramework | Example |
| --- | --- | --- | --- |
| [Basic](Basic/README.md) | No | No | BaseUnityPlugin, configuration |
| [UI](UI/README.md) | No | Yes | Window, scaling, toggle, cursor |
| [ApiUI](ApiUI/README.md) | Yes | Yes | Activation, dialog, alert, restart |

Build instructions and path configuration are covered in each project's README. Before publishing your own plugin, replace the example GUID/name/author and choose a license for your code.
