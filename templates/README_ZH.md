# BCL 插件模板

三个独立模板，面向 MadOut2 PC 9.4 / BepInEx 5 / net472：

| 目录 | BCL API | LegacyUIFramework | 示例 |
|---|---|---|---|
| [Basic](Basic/README_ZH.md) | 无 | 无 | BaseUnityPlugin、配置 |
| [UI](UI/README_ZH.md) | 无 | 有 | 窗口、缩放、开关、光标 |
| [ApiUI](ApiUI/README_ZH.md) | 有 | 有 | 启用与禁用、对话框、提示、重启 |

构建方法和路径配置见各项目的 README。发布自己的插件前，请替换示例 GUID、名称和作者，并为自己的代码选择许可证。
